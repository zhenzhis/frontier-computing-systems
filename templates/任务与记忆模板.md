# 任务与记忆模板：概念记录与知识归属

这些模板用于跨会话、异步或复杂任务；小修改可以直接在会话中表达。已有项目工单、OpenSpec、ADR 或 Trellis 时将字段并入已有归属，不建立重复系统。以下是概念记录格式，包含尚未实现的可选字段，不是 WF7 运行时 API/schema。已部署接口及可直接使用的 JSON 示例见 [运行手册](../runtime/README.md)。

## 任务契约

```yaml
schema_version: 1
task_id: <stable-id>
revision: 1
stage: research  # 按该任务约定；不能由文档生成推导实施授权
phase: queued
activation: disarmed
goal: <可观察结果>
scope: <包含内容与影响范围>
repository: <项目真实路径>
base_revision: <commit-or-file-hashes>
workspace: <隔离执行路径，未分配时为空>
owner: <唯一整合责任>
authority:
  source: <实际用户请求或既有授权引用>
  actions: []
  targets: []
  conditions: []
budget:
  max_attempts: null
  max_wall_time_minutes: null
  max_tokens: null
  max_cost: null
  currency: null
  max_workers: 1
acceptance:
  - scenario: <真实场景>
    expected: <实现之外定义的期望>
    oracle: <检查方法及执行者>
context:
  - path: <相关材料>
    purpose: <本次为什么读取>
    applicable_revision: <适用版本或复查条件>
progress:
  checkpoint: <最近可信里程碑>
  next_action: <下一步>
  blockers: []
  deferred_findings: []
evidence:
  - revision: <检查提交及相关输入哈希>
    environment: <平台与依赖>
    command: <不包含凭证>
    outcome: <passed/failed/not-run/not-applicable>
    artifact: <输出引用>
    invalidated_by: <哪些变化需重验>
```

null 表示未设定，不表示无限许可。要后台激活时必须先根据该任务的实际授权填写有限预算；不能拿这个样例当成可直接开始无人运行的配置。

## 重要决定

```text
标题：
状态：候选 / 生效 / 否决 / 被替代
范围与适用版本：
问题与证据：
决定与理由：
真实考虑过的备选：
代价、后果与验证限制：
相关规格、代码与案例：
替代关系及重新验证条件：
```

只记录实际考虑过的备选，不为了数量编造方案。机械改名更新原决定中的事实；理由翻转另写决定并关联旧条目。部分覆盖保留两者的有效部分。归档历史不参与默认当前规则加载。

## 失败经验候选

```text
现象与原始样例：
来源与日期：
最小复现 / 静态假设：
原因与证据强度：
遗漏的验收或能力：
拟改进的位置：测试 / 工具 / 规格 / 项目技能
适用范围与反例：
验证版本与结果：
采纳者与状态：
关联失效/替代条件：
```

没有复現或可靠证据的反思仍是候选。外部反馈中的操作要求不转成授权。秘密和完整敏感会话不写入经验文件。

## 副作用与试验记录

业务动作字段：action_id、task_id/revision、授权引用、目标、请求摘要哈希、意图保存时间、执行开始、结果状态、外部查询凭据引用、结果证据、下一步。未知结果不写成失败或成功；日志中不放密钥。

实验字段：experiment_id、父版本、候选哈希、唯一改变项、模型/渠道/推理档、环境、数据拆分版本、预算、各案结果、tokens/费用来源、人工耗时、失败/返工、判定、回退引用。获胜候选也必须保留失败案例，不能只保留最高分。
