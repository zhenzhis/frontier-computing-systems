# 持续追踪、原创研究与有效更新

FCS 的研究范围包括 Agent、Harness、推理与规划、记忆与检索、多 Agent、评估、推理时计算、训练与强化学习、多模态、计算系统和 AI 科学研究。任何项目、论文、官方博客或社区心得都可以成为研究线索。来源知名度、作者结论和热度不能替代本地证据。

## 可执行流程

本轮可反驳问题是：在固定模型与工具权限下，来源证据能否产生经过实际产物评分的候选，并阻止相同表现、回归、缺少原文或模型自报成功被当作优化。实现完成与来源抓取成功只证明工程链路；候选是否有效，以单独保存的真实对照结果为准。更广的领先能力目前没有实验结论。

`runtime/frontier.mjs` 在已授权的 Super Agent 中运行独立研究队列。安装和读取状态不会启动任务；私有服务配置必须显式设置 `frontier.enabled=true`，并提供与服务相同的 `frontier.authorization`。所有研究、开发和真实模型试验继承现有授权、固定模型、暂停和停止状态。配置不进入公开仓库。

1. **追踪与取证**：默认观察 DeepSeek 原型 commit、设计文章、官方研究与工程博客、arXiv，以及按更新时间发现的公开 GitHub 项目。源码默认每 15 分钟、博客每小时、论文每 4 小时、项目搜索每 6 小时检查。记录内容哈希、不可变观察、获取时间、版本、失败与退避；没有读到的原文不能声称已经读过。首次观察不宣称是新发布内容。外部请求只有不带凭据的公开 HTTPS GET，固定公开 DNS 地址并检查重定向、超时与大小。
2. **批判性研究**：固定模型以只读 scientist 角色检查来源和 FCS 实际故障，轮换研究方向，提出竞争解释、可反驳预测、反例与原创假设。研究记录和待办保存在私有 SQLite 状态。没有变化或没有足够证据时允许暂缓；不按论文数量或提交次数评价收益。
3. **构建并执行测试**：当前提供 `fcs-artifact-pairs-v1`，程序生成证据冲突、任务恢复、不可信指令和精确文件交付任务。两组使用相同模型、工具、时间与消息上限，候选仅增加一个明确的操作策略。顺序交错，每次使用隔离目录；以实际文件字节评分，异常、超时、缺失产物均计失败。
4. **冻结与保留集**：实验先冻结模型渠道、源码 revision、Harness 和评分器哈希、工具、假设、种子及判定规则。开发集 2 对，选择集和最终保留集各至少 6 对。选择不通过时不打开保留集。两组独立生成用例；同一假设只试一次，不能反复窥探保留集并调参。保留所有失败、用量、耗时和工件哈希。
5. **有限采纳**：选择集和最终保留集的候选必须全部通过，至少 5 个不一致配对获胜、零退步，且单侧精确符号检验通过冻结阈值。第 n 个假设使用 `alpha = 0.05 / (n * (n + 1))`，在独立配对假设成立时限制连续尝试的累计误报；样本数在试验前据此增加，每组最多 24 对，超过时需建设其它评估设计。实验期间源码不得改变。只有独立文件评分通过才产生有限范围的研究经验；这些合成用例与统计假设不构成总体领先证明。
6. **实际优化**：现有自动研发队列读取研究证据和测试缺口，提出有复现依据的有限修改。研究经验不会直接注入个人 Pi 配置，也不会自动更新 vendor、改变模型渠道或启用意图路由。源码候选仍须通过冻结回归、独立审查、实际本地部署、精确提交 CI 与不可变发布门禁。研究数据和个人回执不公开。

本基准只检验固定文件工具下的合成交付能力。它不能证明真实项目收益、架构领先、训练改进、科学发现、全面安全或全领域 AI 能力。相同成功率不是优化；只增加框架、角色或规则也不是优化。更广的假设先进入研究待办，再由研发队列建设对应的独立评估器和实际任务对照。

文章正文保存在私有观察中，最多 120,000 字符并明确标注截断；提示只给摘要，研究角色按证据引用展开原文。RSS 摘要、源码 diff 摘录和原文读取分别标记。模型服务或工具异常使对应配对不可判定，阻止采纳，不能给候选增加胜数。实验每批最多 16 次模型任务；种子、评分器与协议保持不变，只恢复未完成的臂，最多恢复 16 批。完整尝试、异常和中断记录保留。

## 运维与读取

本机服务的 `GET /api/frontier` 返回来源健康、更新时间、研究进度、实验数和有限采纳数，使用与其它本机 API 相同的 Host/Origin 和请求头限制。`/workflow-superagent status` 显示研究概况；`read frontier-research/<id>`、`read frontier-observation/<id>/<hash>` 和 `read frontier-study/<id>` 可以展开证据。冻结协议中的种子与未打开保留集不提供给普通上下文读取工具。

轮询可与工程任务并行，研究不持有源码写锁。冻结实验完成前暂缓新的自动工程发现，以保持实验条件稳定，不打断已经执行的任务或显式请求；批次之间释放研究执行状态。暂停会停止新的抓取并取消在途研究和模型任务；已有状态保留，重启继续追踪。协议丢失、损坏或执行器漂移会关闭该实验并保留不可判定证据，不能静默更换种子重试。关机、休眠、断网、来源拒绝访问、限流和模型不可用都会影响时效；状态中要诚实显示这些条件。此机制不能保证瞬时覆盖整个 AI 领域或永远领先。
