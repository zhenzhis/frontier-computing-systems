# ADR 0001：独立公开项目与私有部署分离

日期：2026-10-14；状态：采用。

目标是持续维护一个可复用的 Pi 工作流，同时保留每版原始部署的回溯性。私人仓库含个人模型、上下文材料、部署收据和历史文件；直接改变 remote 或复制整个历史会混淆公开源码与实际运行状态。

采用独立公开 Git 历史，从版本 0.1.0 开始。只移植明确选择的运行机制、权限适配、按需资源、模板和可公开研究摘要。私人完整快照与全部旧版本先在指定私有备份位置加密保存，公开源码单独每版备份。

新项目为维护源，但当前正在使用的私人部署继续保持原状态。将来部署必须说明源码版本、目标配置、备份和验收；源码 tag 本身不证明部署已经完成。新控制器使用独立状态命名空间，不悄悄迁移旧任务。

意图分流继续暂缓，见 [两轮研究与决定](../research/intent-routing.md)。本次开源不等于采用此前所有研究建议。
